# My datalexicon Project

This project is a starter workspace for datalexicon.

## Structure

- models/ - logical model YAML files
- standards/ - naming, glossary, and abbreviation configuration
- datalexicon.yml - project configuration

## Next steps

1. Add logical models under models/
2. Define naming conventions in standards/naming.yml
3. Add business terms in standards/glossary.yml
4. Add abbreviations in standards/abbreviations.yml
5. Run `datalexicon validate` and `datalexicon build`
